# Release Checklist

- [ ] Quick-capture contract is accepted and implemented without data loss.
- [ ] Demo data is distinguishable, idempotent, removable, and preserves user records.
- [ ] Every Insights claim has deterministic tests and minimum-sample behavior.
- [ ] Notification permission, scheduling, cancellation, and review paths pass on device.
- [ ] Production configuration builds.
- [ ] Required automated tests pass.
- [ ] Fake and preview data are excluded from production.
- [ ] Debug controls and staging endpoints are removed or protected.
- [ ] Permissions match real behavior.
- [ ] Privacy policy and terms match actual data practices.
- [ ] Accessibility and supported layout scenarios are reviewed.
- [ ] Persistence and migration behavior are verified.
- [ ] Known limitations are documented.
- [ ] Rollback or recovery plan exists where applicable.
